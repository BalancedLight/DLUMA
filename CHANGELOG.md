# Changelog

## 0.5.1

- Add optional nightly updates and a way to restore the saved stable package.
- Improve audio catalog searches and previews, menu navigation, and the Third Person example's camera and interaction controls.
- Preserve mod configuration and mod data during local package updates.
- Allow global mods with `world.write` access to use transient player-variable overrides.
- Add a HUD surface API for mod authors; its Player backend is not yet available.
- Support longer mod configuration text values, including file paths.
- Keep compatible existing native mod packages working after the API catalog update.

## 0.5.0

- Rename the project and mod API to DLUMA — Dying Luma.
- Prepare a Steam Workshop package and a public source distribution.
- Include native mod examples and updated SDK documentation.
- Add a first-launch notice with a saved acknowledgement.
- Show the custom-project reset option only in Developer Mode.
- Improve option descriptions and mod enable dialogs.

Earlier development releases used the Dying Light Mod Workbench name.
