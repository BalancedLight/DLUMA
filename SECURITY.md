# Security

DLUMA loads community mods into Dying Light. Install mods from authors you
trust and review their requested permissions before enabling them.

Native and managed mods run code inside the game process. Lua mods use the
permissions declared in their manifests. Approval applies to the selected
mod files; changed files may require approval again.

## Reporting a vulnerability

Report security issues privately to the repository maintainer. Use GitHub's
private vulnerability reporting feature when it is available. Do not post
credentials, personal information, or exploit details in a public issue.

Include the DLUMA version, affected mod type, steps to reproduce, and the
potential impact. Remove personal paths and other private information from
logs before sharing them.

For ordinary bugs and crashes, use the repository's issue tracker.
